# Interactive Image Gallery

A clean, responsive web gallery featuring smooth hover animations and an interactive lightbox modal view. Built using semantic HTML5, modern CSS3 (Grid & Transitions), and vanilla JavaScript.

---

## Features

* **Responsive Grid Layout**: Auto-fitting multi-column grid displaying 8 curated images seamlessly across mobile, tablet, and desktop screens.
* **Hover Micro-interactions**: Smooth zoom (`scale`) and brightness transitions on hover for an engaging browsing experience.
* **Lightbox Preview Modal**: Clicking any image opens a high-resolution focused preview overlay.
* **Multiple Exit Controls**: Close the lightbox view by clicking the close button (`×`), clicking the dimmed backdrop, or pressing the `Escape` key.
* **Pure Vanilla Implementation**: Zero external libraries or heavy dependencies—built purely with native browser APIs.

---

## Tech Stack

* **HTML5**: Semantic structure and accessible markup.
* **CSS3**: CSS Grid, Flexbox, backdrop filters, and CSS transitions.
* **JavaScript (ES6+)**: DOM manipulation and keyboard/mouse event listeners.
